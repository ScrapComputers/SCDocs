sc.time

A Time module that allows you to format time differently

Functions​

formatEpoch​

sc.time.formatEpoch( epoch )

Formats an EPOCH to SS, MM, HH, DD, MM, YYYY

Arguments:

  • epoch [ number ] The epoch time.

Returns:

  • [ number ] Total seconds
  • [ number ] Total minutes
  • [ number ] Total hours
  • [ number ] Total days
  • [ number ] Total months
  • [ number ] Total years
